# Greeting Board

## Problem Statement

There is no quick, no-friction way to show a friendly, personalized greeting
on screen — most tools require an account, a backend, or several steps before
showing a simple, pleasant message back to someone.

## Solution

Greeting Board is a single-page web app: a visitor types their name into a
field and presses a Greet button to see a friendly greeting built from that
name. There is no backend and no sign-in — everything happens on the one
screen.

## Actors

- Visitor — opens the page, enters a name, and presses Greet to see their
greeting. No account or sign-in.
